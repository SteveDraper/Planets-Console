# Homeworld assertions as tiered provenances on two axes

Status: accepted

**Homeworld locator** annotations (#37) treat **ownership** (whose sector / whose planet) and **location** (which planet is the HW) as independent evidence axes. Each axis keeps a provenance list; every provenance kind maps to a **homeworld evidence strength class** (`weak` < `strong` < `asserted`). Decision and display state are derived by **max-strength resolution** (same-strength conflicts stay ambiguous / possible). **Location** resolution is **per homeworld sector** when a sector partition exists (one definite location per sector ≈ per player); without sectors it remains a single global location axis. This replaces the earlier plan of a durable binary `inferred` | `user_asserted` **homeworld attribution** flag that rewrote whole **homeworld candidate records**.

**Why not attribution-on-record:** ownership already accumulates machine provenances on sector owner sets (#269); collapsing user confirms into a row-level flag created a second source of truth, could not assert the axes independently, and hid weaker evidence under an assert. **Why not turn-scoped asserts:** annotations are shared across viewers and must survive evidence wipe / refresh; they belong in **homeworld locator state (game-global)** per ADR 0002 split scope. **Encapsulation:** a thin merge layer immediately above persistence read unions game-global **asserted** provenances with machine provenances from the shell **homeworld evidence aggregate**, so inference and materialize see one list per axis and do not know the storage split.

**v1 product locks:** positive location assert only (revoke to undo); no durable race annotation (SPA shows `"<name> (<race>)"` → slot); location assert may create a candidate on any traditional planet; ownership is sector-keyed when sectors exist, planet-keyed only when they do not; refresh clears machine state and `force_fresh` rebuilds while preserving asserts. **Viewpoint pin:** prefer the shell perspective owner's observed (definite) homeworld; for spectator / pseudo-observer (`perspective == 0`), bootstrap from any asserted location planet when present.
